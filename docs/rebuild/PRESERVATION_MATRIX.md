## Feature completeness rule

The matrix groups related functions; machine-readable API_INVENTORY.json contains every registered route from both source trees and frontend exported client function. Missing Desktop counterpart requires a specific phase assignment, not silent removal. All six stage names/order remain Transcribe, Clean, Sections, Layout, Polish, Export. Debug-only routes are not a packaged end-user feature and must stay disabled in production.
